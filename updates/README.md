# 개인별 준비 상태

`<github-id>-YYYY-MM-DD.md` 파일 하나에 아래 양식을 복사해 작성합니다. 같은 날의 추가 결과는 작성 시각과 함께 갱신하면 됩니다. 모르는 값은 `미확인`, 실행하지 않은 것은 `미실행`으로 적습니다.

```text
이름 / GitHub 아이디:
작성 시각 (KST):
읽은 공통 컨텍스트 커밋:
맡을 수 있는 역할:
행사 전 가능 시간 / 행사 중 참여 가능 시간:
가져갈 장비 (모델·케이블·전원):
지금 실제로 되는 것:
근거 (실행 명령·로그·파일·공식 링크):
아직 실행하지 않은 것:
막힌 점 (오류 원문 또는 부족한 부품·권한):
다음으로 완료할 작은 작업:
팀장에게 필요한 결정:
```

실습 후에는 다른 사람이 재현할 방법과 실제 결과를 남깁니다. 생성된 코드와 실행된 코드를 구분하고, 로그에 키·토큰·개인정보가 없는지 확인합니다. 파일을 올린 뒤 공유할 때는 파일 링크와 커밋을 함께 사용합니다.

이 폴더의 보고만으로 최종 트랙·역할이 확정되지는 않습니다. 팀장이 확인한 결정은 CONTEXT.md에 반영합니다.
