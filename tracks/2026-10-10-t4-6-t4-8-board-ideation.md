# Uno Q·ClikaRT·NU-40·NU-87로 여는 T4-6·T4-8 아이디어 11개

2026-10-10 KST. 상태: **발산·선행사례 교차검증. 순위·최종 선택·구현 착수 없음.**

최신 사용자 요청은 T4-6과 T4-8을 함께 탐색하는 것이다. 앞선 T4-6 고정 결정은 이력으로 보존하고, 현재 논의 범위에는 T4-8을 다시 포함한다. 이것이 두 과제 동시 출품 결정은 아니다. 기본 참가 규칙은 메인 트랙 하나의 문제 하나이며 최종 제출 문제·SC는 별도로 결정해야 한다.

이 문서는 서로 다른 물건과 사용 장면을 만든 뒤, 이미 있는 해법과 겹치는 부분 및 실험으로 확인할 차이를 나눴다. 상용 제품·특허·원 논문을 확인했지만 완전한 시장·특허 조사가 아니며, 검색에서 동일 제품을 못 찾았다는 이유로 신규성을 주장하지 않는다. 현장 정비사·교관·이번 심사위원과 면담한 결과는 없다. 아래 반론은 공개 자료와 사용자 경험에서 도출한 예상 질문이다. 보드·모델·계측·3D 출력·사용자 비교 실험은 수행하지 않았다.

10/10 공식 B-2 시트를 재조회했다. T4-6의 저장·재연결 동기화·대시보드 등은 예시란의 구현 방향이며 모두 별도 필수 제출물이라는 뜻은 아니다. T4-8의 필터·데드존·정지·촉각 피드백도 공식 예시에 이미 있다. 이런 기능을 새 발명처럼 제시하지 않는다. ATE로 확장한 T4-6 범위는 운영진이 별도로 승인한 상태가 아니다.

아래 T4-6은 일반 전자 시험대·저전압 모형에서 연구할 장치다. T4-8은 비무장 교육용 드론 시뮬레이터의 입력 인터페이스로 한정한다. 군용 장비 수리 절차나 실제 비행 제어 구현은 이 문서의 산출물이 아니다.

## 3. T4-6: 관찰 대상이 다른 여섯 장치

### M1. 릴레이의 실제 부하 이력을 기억하는 작은 캡슐

- **장면:** 정비사가 반복 사용한 스위칭 모듈에 캡슐을 붙인다. 같은 횟수로 작동한 두 채널 중 어느 쪽을 먼저 점검할지 볼 때, 작동 횟수뿐 아니라 실제 부하·온도·주기적 접점 측정의 변화가 함께 나타난다. 단순 계수기에서 '어떤 조건에서 사용됐는가'로 관측을 확장하는 물체다.
- **하드웨어:** 외부 전류·온도 센서와 점검 시 접점 측정 인터페이스 → NU 노드 조건부 → Uno Q. Uno Q는 사용 조건별 특징과 상태 추세를 결합한다. ClikaRT는 선택한 추론 모델을 이 타깃에서 실행할 수 있을 때만 적용한다. 내장 보드에 전류 계측 정확도나 고속 과도현상 포착 능력이 있다고 가정하지 않는다.
- **가까운 기존 제품:** [Pickering BIRST/eBIRST](https://blog.pickeringtest.com/effective-pxi-test-system-maintenance-white-paper)는 이미 경로 저항으로 고저항·불량 릴레이를 찾는다. eBIRST는 외부 인터페이스까지 검사한다. 같은 문서는 부하·사고·배치 차이 때문에 횟수만으로 수명을 판단하는 한계를 설명한다. 진단기 자체가 새롭다는 주장은 불가하다.
- **검증할 차이:** 기존 자가진단을 넣기 어려운 범용 장비에서, 후부착 노드의 사용 이력과 주기적 측정을 결합하면 횟수 또는 현재 저항만 쓰는 기준보다 교체 시점의 불확실성을 줄일 수 있는가?
- **예상 반론:** '기존 모듈의 내부 채널별 부하를 어떻게 구분하지? 센서 설치와 기준 측정이 정비 일을 늘리지 않나?' 실제 접근 가능한 신호와 작업량이 핵심이다.
- **비교지표:** 단순 횟수·저항 임계값 대비 사전 경고 시간, 놓친 열화와 불필요 점검, 채널 식별 오류, 설치·점검 시간. 모델을 쓰면 동일 입력에서 최적화 전후 지연·메모리·예측 변화도 별도 비교한다.
- **종료점·자료:** 정해진 시험 조건에서 접점 저항 또는 동작 안정성이 허용범위를 벗어나는 시점까지의 시간/작동 횟수. 서로 다른 부품 개체·부하·온도에 대한 열화 진행과 종료 측정이 필요하다. [Pickering 수명시험 설명](https://www.pickeringrelay.com/reed-relay-life-expectancy/)도 용도에 맞는 부하 조건과 접점 측정의 중요성을 보여준다. 몇 번의 고장 주입은 실제 잔여수명 자료를 대신하지 않는다.

### M2. 케이블이 얼마나 꺾이고 당겨졌는지 남기는 탈착식 목걸이

- **장면:** 정비사가 자주 움직이는 시험 케이블의 커넥터 뒤에 작은 고리를 채운다. 사용 후 끝단을 확인 도크에 꽂으면, 취급 이력과 전기적 상태가 같은 케이블 ID 아래 겹쳐 보인다. 꽂은 횟수가 같은 두 케이블도 다르게 다뤄졌음을 관찰하는 장면이다.
- **하드웨어:** 굽힘·변형을 측정할 수 있는 외부 센서와 온도, 도크의 별도 전기 측정 회로. NU는 고리의 저속 취급 신호를 취득할 수 있을 때 노드로, Uno Q는 취급 이력과 기준 측정을 연결하는 역할로 둔다. IMU 하나만으로 케이블 내부 변형이나 순간 단선을 직접 측정한다고 주장하지 않는다.
- **가까운 기존 제품·특허:** [igus CF.Q](https://www.igus.com/preventive-maintenance/sensors-for-cables)는 이미 케이블 상태를 저항과 온도로 관찰한다. [Tektronix 케이블 상태 표시 특허](https://patents.google.com/patent/US12055603B2/en)는 사용 이력·표시뿐 아니라 열·충격 등에 반응하는 재료까지 기재한다. '취급 이력 추가'만으로 신규성을 주장할 수 없다.
- **검증할 차이:** 특정 수동 취급 케이블에서 여유 도체 없이 탈착 고리와 짧은 도크 점검을 결합하는 방식이 실제 열화 판단에 유용하며 작업 부담이 더 적은가? 시장에 없는 기능이라고 단정하지 않는다.
- **예상 반론:** '밖에 붙인 센서가 내부 단선을 어떻게 알아? 그 고리가 케이블을 더 뻣뻣하게 만들지는 않나?'
- **비교지표:** 취급 이력만·전기 측정만·둘을 결합한 경우의 미탐/오탐, 경고 여유, 고리 자체의 기계적 영향, 도킹 추가 시간, 다른 케이블로 바꿀 때 재학습 비용.
- **종료점·자료:** 정의된 확인 조건에서 간헐 연결 이상 또는 경로 저항이 허용범위를 벗어나는 시점. 케이블별 취급 이력, 반복 전기 측정, 환경, 최종 결함 확인이 연결된 자료가 필요하다. 취급 강도 점수는 그 자체로 RUL이 아니다.

### M3. 팬과 필터를 따로 관찰하는 탈착식 흡기 후드

- **장면:** 정비사가 시험기 흡기구에 작은 후드를 설치한다. 온도가 올라갔을 때 무조건 팬 교체 알림을 내는 대신, 공기 흐름 저하·팬 회전 상태·장비 부하를 함께 보여준다. 팬 교체와 필터 점검 중 무엇을 먼저 확인할지 근거를 얻는다.
- **하드웨어:** 차압/유량 계측, 흡배기 온도, 가능한 경우 팬 회전 또는 진동과 부하 맥락. NU 노드는 해당 센서 취득이 가능할 때, Uno Q는 부하 조건별 상태 비교와 예측, ClikaRT는 호환 모델 추론에 사용한다. 후드 자체가 냉각을 방해하는지도 비교 대상이다.
- **가까운 기존 제품:** [Vaisala PDT101 데이터시트](https://docs.vaisala.com/api/khub/documents/grdSorrvWg6kcTWQHyQWgQ/content)는 팬·필터 차압 측정을 명시한다. 무선 진동·온도 감시와의 비교는 [앞선 선행사례 조사](2026-10-10-t4-6-deep-research.md)를 참고한다. 차압 센서나 무선 전송은 차별성이 아니다.
- **검증할 차이:** 불규칙한 시험 부하와 팬 제어가 있는 구형 시험기에서, 온도 경보 하나보다 필터 막힘·팬 상태·부하 증가를 덜 혼동하고 정비 전조를 관찰할 수 있는가?
- **예상 반론:** '모든 시험기의 흡기 구조가 다른데? 팬 속도를 소프트웨어가 바꾸면? 필터 없는 장비는?'
- **비교지표:** 온도 단일 경보 대비 원인 분류의 혼동, 정비 임계치 전 경고 시간, 정상 고부하에서 오경보, 후드 장착 전후 냉각 변화, 장비별 설치 시간.
- **종료점·자료:** 특정 부하·주변 조건에서 최소 냉각 성능 또는 허용 온도 여유를 더 이상 유지하지 못하는 시점. 필터 상태·팬 상태·환경·제어·부하가 구분된 반복 자료가 필요하다. 필터 정비 임계치까지의 시간과 팬 부품 파손까지의 RUL은 따로 표시한다.

### M4. 예비 모듈을 주기적으로 깨워 보는 대기 서랍

- **장면:** 정비사가 예비 모듈을 보관 슬롯에 넣는다. 서랍은 허용된 확인 절차에서 전원 투입 이후 기준 출력이 안정될 때까지의 변화를 기록한다. 실제 교체를 시작하기 전에 '이 예비품은 마지막 확인에서 어떤 구성으로 얼마나 안정됐는가'를 볼 수 있다. 자동 설정 복원이나 사용 승인을 대신하지 않는다.
- **하드웨어:** 범용 저전압 모듈용 슬롯, 독립 기준 신호/부하와 측정기, 온도 센서, 모듈 식별. Uno Q는 확인 프로필과 시간 이력을 관리하고, NU는 슬롯 센서 노드로 조건부 사용한다. 실제 ATE 모듈의 전원·인터페이스를 보드가 바로 지원한다는 뜻은 아니다.
- **가까운 기존 제품:** [NI SystemLink 신뢰성 가이드](https://www.ni.com/en/shop/labview/labview-plus-suite/level-up-your-automation/best-practices-reliable-repeatable-distributed-test.html)는 구성·교정·지원되는 자체시험·준비 상태를 이미 다룬다.
- **검증할 차이:** 재고·교정 유효 여부 외에 기동 후 안정화 이력이 예비품 교환 후 뒤늦게 발견하는 문제를 더 일찍 드러내는가? 오늘 사용자가 말한 설정 부담과 이 문제가 실제로 연결되는지는 미확인이다.
- **예상 반론:** '보관품을 자꾸 켜는 것 자체가 수명과 작업을 늘리지 않나? 서랍에서는 되는데 실제 랙에서는 안 되면?'
- **비교지표:** 재고·교정 날짜·마지막 합격만 보는 기준 대비 교체 후 확인 실패, 재현된 준비 시간, 점검 추가 작업, 확인 장치와 실제 구성 간 판정 불일치.
- **종료점·자료:** 특정 확인 프로필에서 정해진 기동 시간 안에 측정 허용범위에 들어와 유지하지 못하는 상태. 같은 모듈의 장기 반복 기동·환경·보관·수리 기록이 필요하다. '이번에 준비되기까지 걸릴 시간' 예측은 복구/준비시간이며 그 자체가 잔여수명은 아니다.

### M5. 장비와 어댑터를 번갈아 통과하는 두 경로 기준 도크

- **장면:** 값이 흔들리기 시작하면 정비사가 기준 도크를 연결한다. 같은 기준 입력을 짧은 기준 경로와 사용 중인 케이블·어댑터 경로에서 비교하고, 지난 확인 이후 차이가 커졌는지 본다. 모듈 교체 전후에도 같은 지문을 남긴다.
- **하드웨어:** 안정성이 별도로 확인된 기준물, 두 경로를 비교하는 측정 인터페이스, 경로·모듈 ID. Uno Q는 경로별 추세와 교체 사건을 연계하며 NU는 환경·접속 상태 노드로 조건부 사용한다. 고정밀 기준물·측정 기능을 Uno Q 내장 성능으로 가정하지 않는다.
- **가까운 기존 제품:** [Cirris Verification Test Plug](https://cirris.com/bad-cable-or-bad-test-fixturing/)는 이미 시험 어댑터 확인 제품이다. [NI SystemLink](https://www.ni.com/en/shop/electronic-test-instrumentation/application-software-for-electronic-test-and-instrumentation-category/systemlink/7-common-test-operations-challenges-how-solve-them.html)는 결과·자산·교정 이력의 연결을 제공한다.
- **검증할 차이:** 단발 합불 확인과 자산 이력에 더해 경로 간 차이의 장기 추세가 어댑터 열화를 더 일찍 드러내고, 재확인할 과거 측정 범위를 줄이는 데 도움을 주는가? 해당 완성 기능이 기존 제품에 없다고 확인한 것은 아니다.
- **예상 반론:** '기준 도크도 고장나면? 경로를 한 번 더 끼워서 불확도가 늘면? 장비 드리프트와 두 경로 공통 고장은 구분하나?'
- **비교지표:** 단발 합불/직전 값 대비 반복성, 모듈·어댑터·기준물 원인 오분류, 추가 접속 시간, 사전 경고 시간, 사후 재확인 범위와 실제 영향 결과의 일치.
- **종료점·자료:** 지정된 조건에서 어댑터 경로의 오차·저항·간헐성이 허용범위를 넘는 시점. 독립적으로 확인한 기준물 안정성, 경로별 장기 자료, 환경·교체 이력과 실제 허용범위 이탈 시점이 필요하다. 그날의 원인 분리 성능과 미래 시점 예측 성능은 별도 평가한다.

### M6. 보드 대신 끼워 치구 접촉 상태를 읽는 점검 판

- **장면:** 정비사가 검사할 PCB 대신 얇은 점검 판을 치구에 넣고 뚜껑을 닫는다. 판은 어느 구역의 접촉 힘·변위·전기 접촉 상태가 이전과 달라졌는지 기록한다. 뚜껑을 더 세게 누르거나 같은 보드를 재검하기 전에 치구 자체 상태를 관찰하는 물체다.
- **하드웨어:** 구역별 힘/변위 센서, 알려진 접점 패턴, 별도 저항 측정 회로, 치구 ID. NU는 구역 센서를 읽을 수 있을 때, Uno Q는 공간별 상태·사용 이력과 예측을 결합할 때 사용한다. 구역별 압력이 개별 핀의 힘과 같다고 가정하지 않는다.
- **가까운 기존 제품:** [INGUN 치구](https://ingun.com/en/applications/pcb-electronic-test/test-fixture-kits-customising-accessories/)는 접촉력·평행 스트로크와 실험실 조건의 반복 수명을 명시한다. [TofuPilot](https://www.tofupilot.com/guides/predictive-maintenance-from-test-data-in-tofupilot)은 이미 접촉저항·산포 기반 치구 상태 관찰을 제안한다. 점검 판의 완성 경쟁제품을 망라한 조사는 아니다.
- **검증할 차이:** 제품 편차가 섞인 생산 시험값과 달리, 같은 점검 판에서 얻는 기계·전기 상태의 조합이 정렬 변화·스프링 상태·접촉 오염을 더 잘 구분하고 교체 필요 시점을 앞서 보여주는가?
- **예상 반론:** '점검 판과 실제 PCB의 두께·강성이 다른데? 눌림 힘이 정상이면서 팁만 오염된 경우는? 치구마다 새 판이 필요하지 않나?'
- **비교지표:** 시험 불합격률·접촉저항만 보는 기준 대비 이상 구역 식별, 원인 혼동, 사전 경고 시간, 매일 점검 소요, 치구 변경 시 제작·설정 비용.
- **종료점·자료:** 정해진 접촉 조건에서 치구가 요구되는 접촉 안정성을 유지하지 못하는 시점 또는 반복 횟수. 치구별 반복 사용·세척·핀 교환·정렬 변경 이력, 힘·변위·저항의 변화와 종료 판정이 연결돼야 한다. 유지보수로 회복된 상태를 단조롭게 진행하는 수명과 혼동하지 않는다.

## 4. T4-6에서 보드 조합과 예측이 필요한 위치

| 후보 | NU-40 / NU-87을 둘 다 쓸 이유가 있다면 | Uno Q·ClikaRT로 검토할 판단 | 이 판단만으로 부족한 것 |
|---|---|---|---|
| M1 릴레이 캡슐 | 이동 모듈의 온도·사용 상태와 고정 시험 위치의 부하 맥락을 분리 수집 | 부하 조건을 반영한 접점 열화 추세 | 전류·접점 계측 회로와 개체별 수명 자료 |
| M2 케이블 고리 | 케이블 쪽 취급 이력과 도크 쪽 전기 확인 결과를 연결 | 취급 이력+전기 추세 모델과 전기 측정만 쓴 모델 비교 | IMU가 내부 단선을 직접 검출하지 않음 |
| M3 흡기 후드 | 흡기·배기 또는 환경과 장비 측 관찰 위치 분리 | 부하·환경 변화와 냉각 상태 변화의 구분 | 차압·유량·온도 등 추가 센서, 장착 영향 |
| M4 대기 서랍 | 예비 모듈 두 슬롯의 센서 노드. 고정 슬롯이면 유선과도 비용 비교 | 기동 이후 안정화 신호의 장기 변화 | 당장 준비되는 시간 예측은 RUL과 다름 |
| M5 두 경로 도크 | 측정 경로 외에 환경·접속 상태 입력 | 공통 변화와 경로별 변화의 장기 추세 | 기준물·도크의 고장과 측정 불확도 |
| M6 치구 점검 판 | 판의 힘·변위 입력과 치구의 반복 사용 상태 분리 | 기계·전기 관측 조합의 열화 판별 | 구역 압력이 개별 핀 상태를 보증하지 않음 |

모두 센서·통신이 실제 지원된다는 조건의 역할 제안이다. 단일 노드로 충분하면 보드를 추가하지 않는다. 간단한 임계값·누적 횟수·추세 회귀를 비교 기준으로 두고, 학습 모델이 더 유용한 경우에 ClikaRT 추론이 의미를 갖는다. 모델 자체의 이득과 런타임 최적화의 이득은 별도로 측정한다.

정비 우선순위의 가설은 추정 한계 도달 시점과 예비품 준비·반출·수리 완료 예상 시점 사이의 여유를 함께 보면, 수명이나 교정 날짜만 정렬할 때와 다른 조치 순서가 필요한 경우를 찾을 수 있다는 것이다. 부품별 조치·대기시간·사용 계획이 있어야 실제 효용을 평가할 수 있다. 수명 숫자만 정렬한 화면으로 정비 효율이 개선됐다고 말하지 않는다.

M4는 준비 상태 관리에 머무르기 쉽고, M5·M6은 현재 진단에 머무르기 쉽다. 각 후보를 T4-6으로 제시하려면 장기 변화와 종료 기준까지 연결해야 한다. 단기간에 만든 모의 열화는 알고리즘 흐름을 설명할 수 있지만 실제 ATE 잔여수명을 검증하지 못한다. 데이터는 시간 구간만 나누기보다 부품 개체를 분리해 평가해야 같은 개체의 신호를 외운 결과와 구분할 수 있다.

## 5. T4-8: 손과 몸의 역할이 다른 다섯 입력 장치

### 먼저 확인한 기존성

#### S1. DJI RC Motion 3: 손목 조종 자체는 상용 기능

- 현재 FAQ의 시뮬레이터 미지원 확인: https://www.dji.com/rc-motion-3/faq . 특정 제품 미지원이 시뮬레이터 시장 전체의 공백이라는 뜻은 아니다.
- 제조사의 직관적·편리하다는 설명은 독립적인 학습 시간 비교 실험이 아니다.

#### S2. Skydio Beacon: 누른 동안 방향을 지정하는 완드도 기존 기능

- 공식 설명서: https://support.skydio.com/hc/article_attachments/1260803945389 (13쪽 PDF, 발행 연도 본문 확인 못 함)
- 제품: https://shop.skydio.com/collections/essential-accessories/products/skydio-2-plus-beacon
- 직접 확인: 설명서 p.9에 버튼을 누르는 동안 방향을 바꾸는 한 손 Wand 인터랙션이 설명된다. 해당 기능은 정해진 추적 상태에서 작동하며 범용 자유도 조작 전체와 같지 않다.
- 후보 검증 질문: 이미 있는 한 손 완드 대비, 특정 시뮬레이터 과제의 오류·피로·익숙해지는 시간이 개선되는가?

#### S3. 3Dconnexion SpaceMouse Compact: 책상 지지형 3D 입력도 기존 제품

- 공식 제품: https://3dconnexion.com/us/product/spacemouse-compact/
- 직접 확인: 책상에 놓인 캡을 밀고 당기고 비틀고 기울여 CAD 내용/카메라를 조작하는 6DoF 제품이며, 다른 손으로 마우스를 사용한다.

#### S4. Hinckley·Pausch·Proffitt, I3D 1997: 양손 기준 좌표와 발 클러치

- 서지: https://www.microsoft.com/en-us/research/publication/attention-visual-feedback-bimanual-frame-reference/
- 원문: https://www.microsoft.com/en-us/research/wp-content/uploads/2016/12/Bimanual-Frame-of-Reference-I3D-1997.pdf
- 직접 확인: 17명의 3D 입력 비숙련 참가자에게 두 물체 정렬과 시각 피드백 없는 손 위치 재현을 비교했다. 양손이 서로에 대한 기준을 제공할 가능성을 지지한다. 실물 두 개와 발판 클러치를 이미 사용했다. 기준 손까지 별도 클러치로 고정하는 변형은 예비 사용자 시험에서 혼란을 일으켰다고 기술한다.
- 경계: 이 논문의 주된 종속변수는 기억 재현 정확도이며, 군 교관 연구·드론 조작 시간 우위의 증거가 아니다.

#### S5. Hincapié-Ramos 외, CHI 2014: 공중 동작은 피로까지 평가해야 함

- 원문: https://hci.cs.umanitoba.ca/assets/publication_files/Consumed_Endurance_-_CHI_2014.pdf
- DOI: https://doi.org/10.1145/2556288.2557130
- 직접 확인: 공중 인터랙션의 어깨 부담을 모형화하고 Borg CR10 지각된 운동 강도와 비교했다. 실험에서 팔을 굽힌 특정 상호작용 배치가 부담을 줄였다.
- 경계: 이 생체역학 지표는 팔 자세·추적 등의 정보에 의존한다. 손목 IMU만으로 같은 지표를 계산하거나 건강·부상 방지 효과를 주장하면 안 된다. 작은 해커톤 비교에서는 주관적 피로, 휴식 횟수, 소요 시간 등을 별도로 기록할 수 있다.

#### S6. Marchal-Crespo 외, Exp Brain Res 2010: 보조 중의 잘함과 학습은 다름

- 논문: https://escholarship.org/uc/item/562235p1
- 직접 원문: https://escholarship.org/content/qt562235p1/qt562235p1_noSplash_a4c4bd7c71bfa493f3b8c8eb0861b958.pdf
- DOI: https://doi.org/10.1007/s00221-009-2026-8 (온라인 2009-10-10, 권호 2010)
- 직접 확인: 가상 휠체어 조향에서 힘을 가하는 스티어링 휠의 필요시 보조와 무보조를 비교하고 1주 후 유지 효과를 평가했다. 학습 이점은 참가자의 초기 수준 등에 따라 달랐다.
- 경계: 힘으로 손을 안내하는 장치의 결과다. 저가 진동 모터가 같은 효과를 낸다는 증거가 아니며, 다른 장치로의 전이를 입증한 것도 아니다.

#### S7. Issartel 외: 매핑의 문제 자체가 연구 대상

- 출판 서지/초록: https://www.open-access.bcu.ac.uk/6875/
- 저자 PDF: https://tobias.isenberg.cc/personal/papers/Issartel_2018_ALC.pdf
- 기기의 움직임을 기기 자체 화면의 3D 물체로 연결하는 매핑과 제한된 운동 범위를 분석한 논문이다. 웹 도구의 원문 재접근이 실패했으나 저자 PDF를 별도로 내려받아 본문을 확인했다. 6.2절은 클러치, 감도와 정밀도의 절충, 거리·속도에 따른 동적 감도 변경을 다룬다. 이런 매핑은 기존 연구가 있으며 AI 없이도 구현할 수 있다. 외부 화면의 시뮬레이터에 성능 수치를 그대로 이전하지 않는다.

### 다섯 후보 비교

각 행은 독립된 발산 후보다. 기능을 모두 한 컨트롤러에 합치자는 제안이 아니다. 추가 센서·모터·발판은 현장 부품 확인이 필요하다.

| 후보/실제 장면 | 기존 겹침 | 남는 차이의 가설 | 경험 있는 교관의 예상 반론 | 비교할 것 |

| **H2. 기준 물체와 조작 도구를 나눈 양손 세트**: 왼손 물체는 화면의 기준 방향, 오른손 도구는 그 기준에 대한 가상 도구 자세를 담당한다. 좌표계가 바뀌는 정렬 문제를 손 두 개로 푼다. | Hinckley의 양손 실물 기준 좌표, 기존 두 손 3D 입력. | 한 손에서 모드를 바꾸는 방식보다 잘못된 좌표계 조작·모드 오류가 줄어드는가? | '양손을 쓰면 그냥 입력 장치를 하나 더 준 효과 아닌가? 양손 협응 학습이 더 오래 걸리지 않나?' | 같은 기능의 한 손+모드 버튼 대 양손; 정렬 오차, 잘못된 축 선택, 조작 시간, 손 바꾸기·새 방향 과제 전이. 센서 두 개/무선 노드 두 개 확보 필요. |
| **H3. 축을 손으로 느끼는 탈착식 짐벌 조작구**: 처음엔 한 축만 움직이는 고리를 끼워 조작하고, 고리를 빼면 두 축/자유 자세로 조작한다. | **H4. 손목 입력과 발 승인을 분리한 조작 장치**: 손목을 편한 범위에서 기울이면 화면 속 움직임 후보가 보이고 발판을 밟는 동안에만 가상 조작에 반영된다. 물건을 집거나 손을 쉬는 동작을 입력에서 분리한다. | Skydio/DJI의 누르고 입력하는 방식과 Hinckley의 발판 클러치. | 손가락 버튼을 누르며 자세를 바꿀 때 생기는 동작 방해를 줄이는가? 발로 의도 표시하는 부담보다 이득이 큰가? | '손발 협응과 추가 휴대품이 생겼다. 발판을 쓰기 어려운 자세에서는 어떻게 하나?' | 손 버튼 대 발판, 동일 IMU/매핑; 오입력, 입력 시작 지연, 오래 누르기 피로, 같은 입력 장치로 새 과제 수행; 손 버튼과 발판 조건은 별도로 비교. 착용형 IMU는 위치 추적 대신 자세·각속도 매핑으로 한정. |

이 다섯 후보의 차이는 각각 지지·양손 기준·물리 제약·신체 부위별 의도 분리·촉각 전달이다. 단순히 그립 이름이나 제스처 목록만 바꾼 후보는 아니다. 어떤 것이 더 좋은지는 아직 판단하지 않는다.

### T4-8 과제에 연결하는 장면과 장비 역할

표의 정렬·경로 과제는 입력 방식의 차이를 설명하는 장면이다. 최종 T4-8 논의에서는 교육용 드론 시뮬레이터에서 기체 방향 맞추기, 지정 구역에 멈추기, 정해진 경로 따라가기처럼 같은 입력을 사용하는 과제로 연결한다. 일반 3D 물체 조작의 효과를 드론 인터페이스 성능으로 바꿔 주장하지 않는다. H3·H5도 실제 IMU 조종 입력이 중심이어야 하며 개인별 교육 피드백 앱만 남으면 T4-7 쪽으로 범위가 달라진다.

| 후보 | NU 보드가 들어가는 물건 | Uno Q·ClikaRT가 기여할 수 있는 부분 | 추가 조건 |
|---|---|---|---|
| H1 손바닥 조작판 | NU-40 또는 NU-87+IMU를 기울이는 캡에 넣음 | 사용자의 중립 자세와 의도적 동작 구간 분류를 검토. 고정 보정·필터와 비교 | 지지와 센서가 만드는 가동 범위·복귀 특성. IMU만으로 위치 3축 추적을 가정하지 않음 |
| H2 양손 세트 | NU-40+IMU와 NU-87+IMU를 각각 기준 물체·조작 물체에 넣음 | 두 입력의 시간 관계·상태 기록. 모델은 쉬는 동작 분리가 유효할 경우에만 | 두 IMU의 기준 정렬·동기화·드리프트가 오히려 오류를 만들 수 있음 |
| H3 탈착식 짐벌 | NU 한 개+IMU를 기구 안에 넣음 | 조작·축 혼동 기록. 모델로 동작 패턴 구분은 가능성이지만 수동 제약 자체는 AI가 필요하지 않음 | 3D 출력 기구의 마찰·간섭·내구, 제약 제거 후 비교 |
| H4 손목+발판 | 손목 IMU 노드와 발판 스위치 노드를 나눌 때 NU 두 개 사용 가능 | 의도적 입력과 휴식 구간을 기록·분류. 발판 승인 자체는 명시적 스위치가 기준 | 발판·스위치·전원, 추가 지연·동시 입력. 의도 추정이 발판 상태를 대신하지 않음 |
| H5 진동 인터페이스 | NU+IMU로 입력하고 별도 진동 구동부를 연결 | 같은 편차에서 고정 경보와 동작 구간별 경보의 해석 오류 비교 | 진동 모터·구동부 미확인. 단순 임계 경보에 학습 모델이 필수는 아님 |

Uno Q는 이 입력의 로컬 수집·추론·평가 기록을 맡는 후보이며 시뮬레이터는 Uno Q나 연동 PC 중 실제 실행 가능한 호스트를 확인해야 한다. 센서에서 화면 반응까지의 전체 지연과 끊김을 기록한다. ClikaRT 추론 시간만 빠르다고 조작 지연이 줄었다고 주장하지 않는다. 화면 실행·시뮬레이터 호환성을 아직 시험하지 않았다.

### 현직 교관이 확인할 만한 비교

- 같은 목표·허용 오차·연습 조건을 제공하고 참가자별 시험 순서를 바꾼다. 선행 게임·조종 경험도 남긴다.
- 사전에 정의한 수행 기준에 도달할 때까지의 시간과 정확도를 함께 기록한다. 실패·포기한 시도도 포함한다.
- 지지형/공중형, 손 버튼/발판처럼 한 요소만 다른 비교로 기구의 효과를 분리한다. 그 다음 고정 매핑+필터와 학습 모델을 비교한다.
- H3의 축 제약·H5의 진동처럼 제거 가능한 도움은 끄고 다시 확인한다. 발판 같은 필수 입력부는 유지한 채 새 방향·새 경로로 평가한다. 보조가 켜진 상태에서 성공한 것과 학습한 것을 구분한다. 하루 비교로 장기 유지 효과를 입증하지 않는다.
- 피로는 반복 전후의 자각 피로·휴식·오입력으로 따로 관찰한다. 손목 IMU만으로 검증된 어깨 피로 지표를 계산한다고 주장하지 않는다.
- 키보드와만 비교했다면 키보드 대비 결과다. DJI·표준 스틱·SpaceMouse를 직접 시험하지 않고 그 제품보다 우수하다고 말하지 않는다.

[NIST의 가상 시험 자료](https://www.nist.gov/el/intelligent-systems-division-73500/standard-test-methods-response-robots/aerial-drone-tests-8)는 반복 가능한 시뮬레이터 평가 장면을 만드는 참고 자료가 될 수 있다. NIST도 실제 연습·시험이 필요하다고 설명한다. 자료를 참고했다는 사실이 NIST 인증·표준 준수나 실제 비행 숙련의 증거는 아니다.

## 6. 현직자·심사위원에게 납득되는 주장의 형태

현직자가 실제로 원한다고 확인된 제품은 아직 없다. 지금 가진 직접 경험은 사용자가 설명한 ATE 구성품·외주·수리의 불편이다. 이를 다른 부대·장비 전체의 발생 빈도나 비용으로 확대하지 않는다. 공개 실무 근거와 ATE 관련 선행 연구는 [앞선 심화 조사](2026-10-10-t4-6-deep-research.md)에 구분했다.

| 판단 지점 | T4-6에서 답할 내용 | T4-8에서 답할 내용 |
|---|---|---|

## 7. 발산을 계속할 때 남아 있는 질문

여섯 정비 장치와 다섯 입력 장치 중 어느 것도 순위를 정하지 않았다. 추가 발산의 축은 다음과 같다.

- 정비 장치: 장비에 계속 붙는가, 정비 때 잠깐 끼우는가, 예비품 보관 중 확인하는가? 이 위치가 센서와 추가 작업량을 어떻게 바꾸는가?
- 조종 입력: 손을 받치는가, 두 손의 역할을 나누는가, 물리적으로 축을 느끼는가, 의도를 발로 표시하는가, 피드백을 피부로 받는가?
- 공통: 네 보드·런타임을 더 많이 쓰는 대신, 추가되는 센서 또는 추론이 기존 방식보다 유용한 관측을 하나라도 제공하는가?

시장에 없다는 단정, 현직자 승인, 실제 잔여수명 성능, 초보자 우위, ClikaRT·보드 실행 성공은 아직 주장할 수 없다. 현재 산출물은 기존 기능과 검증할 차이를 명시한 아이디어 묶음이다.
