## 이번 검토에서 분명해진 점

**공식 과제와 팀의 추천은 다르다.** 10/9에 다시 읽은 일정·참가 안내·세부 과제는 앞서 확인한 같은 날의 자료와 같았다. 당시 T4-8·T2-1 우선 검토 제안은 자료 접근이나 장치 동작이 준비됐다는 뜻이 아니었으며, 10/10 T4-6 결정 이후의 우선순위로 사용하지 않는다.

**T4-8은 조작 시연 다음에 비교가 필요하다.** 움직임에 따라 화면이 반응하는 것에 더해 초보자의 학습 시간과 정확도를 함께 보여줘야 한다. 실제 드론 없이 시뮬레이터를 쓸 수 있지만, 단순 화면 토이가 인정되는지는 확인 대상이다.

**T4-6은 이상 탐지와 잔여수명을 구분해야 한다.** 팬의 소리가 바뀌었다고 알아내는 것과 언제 고장 날지 추정하는 것은 다른 문제다. MIMII는 정상·이상 소리 자료이고 C-MAPSS는 엔진 열화 시뮬레이션이다. 어느 자료도 현재 책상 위 장비의 실제 수명을 곧바로 증명하지 않는다. [상세 데이터 검토](T4.md)

**T2-1의 경쟁력은 답의 근거를 확인할 수 있는가에 있다.** 기사 두 개가 같은 발표를 옮겼다면 독립 근거 두 개가 아닐 수 있다. USGS·JMA 자료의 발생·수정 시각, 과거 기록 확보, 인용의 정확성을 먼저 확인한다. 현재 피드만으로 과거 사건 전체 기록을 받을 수 있다고 가정하지 않는다. [접근 조건과 검증 항목](T2.md)

**T4-7은 장비 교육 방향도 있다.** 공식 문제는 전술 판단 피드백 또는 장비 숙련을 높이는 개인화 적응형 훈련 시뮬레이터를 다룬다. 공개된 장비 절차와 정답 자료를 이용한 교육 후보를 검토했고, 개인별 피드백이 다른 문제의 수행에도 도움이 되는지 확인해야 한다고 판단했다. 10/10 T4-6 고정 후에는 미채택 검토 이력이다. [T4 세부 분석](T4.md)

## 기존 세 아이디어는 어디에 해당할까

| 기존 아이디어 | 현재 과제와 만나는 부분 | 남아 있는 차이 |
|---|---|---|
| 이동형 통신 중계 로봇 | T4-1의 통신 수단 일부 | 공식 요구에는 단말 사이 정보 공유와 온디바이스 요약도 있음. 이동 로봇 자체로 충족하지 않음 |
| 장비 내부의 부품 회수 기계 | 정비 작업의 물리적 불편 해결 | 현재 21개 문제에서 직접 대응하는 전용 과제를 확인하지 못함. 연결될 업무·과제부터 확인 |
| FOD 발견·회수 로봇 | 비행장 안전·일상 유지관리 | T3-3의 방공·방어 목적에 포함되는지 미확인. 기존 FOD 탐지 기술과의 차이도 필요 |

FOD는 중요한 항공 안전 문제이고 이미 탐지·제거·평가 연구가 있다. 우리 제안의 차이는 실제 현장의 병목에서 찾아야 한다. 발견 이후 확인·인계·회수 증빙이 끊기는 문제가 있는지는 검증할 가설이다. [FAA FOD 자료](https://www.faa.gov/airports/airport_safety/fod), [T3의 범위 검토](T3.md)

## 참가 조건에서 놓치지 않을 것

- 기본은 메인 트랙 하나의 문제 하나다. T3-1·2는 개념 중심 결과와 중복 참여가 허용되지만, T3-3은 단독 선택과 작동 결과물이 필요하다.
- SC1·SC2는 선택 사항이다. SC1은 ClikaRT의 네트워크 차단 실동작, SC2는 NUCODE 보드 실동작이 필요하다. 표에 두 SC가 나란히 있어도 모두 필수라는 뜻은 아니다.
- 공식 안내는 NO SLIDES이며 T3-1·2에는 예외가 있다. 제출 마감은 **10/11 10:00 KST**다. 행사 종료 시각인 16:00와 구분한다.
- 기존 작업 활용 시 이번 행사에서 새로 만든 부분을 표시한다. 컨셉 이미지·렌더·합성 입력·실물 시험의 증거를 서로 바꿔 설명하지 않는다.
