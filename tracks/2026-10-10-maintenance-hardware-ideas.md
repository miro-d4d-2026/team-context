## 1. 이번 대화에서 확정한 것

- 사용자는 직접 하드웨어를 만들고 싶으며, TA/FA-50 항공전자장비 정비 경험을 문제 선정에 활용하고 싶다고 밝혔다.
- 다른 팀들이 드론이나 완성된 장비를 가져오는 상황에서, 우리 결과물도 경쟁할 만한 수준이기를 원한다. 이는 사용자의 현장 인식과 목표이며 다른 팀의 성능·준비 상태를 조사한 결과는 아니다.
- 마지막 지시에서 **T4-6을 고정**했다. 앞서 검토한 T4-7 훈련 키트로 전환하지 않는다.
- 현직자들이 많아 아이디어 선정 기준이 엄격하다는 조건을 전달했다. 아래 검토 기준은 이를 반영한 팀 내부 제안이며, 운영진이 새로 발표한 심사 기준이나 현직자의 승인 결과가 아니다.
- 이 문서는 대화와 조사 결과를 공유하는 기록이다. 제작·펌웨어 실행·센서 계측·성능 비교를 완료한 기록은 아니다.

## 2. 사용자가 직접 설명한 정비 경험

다음은 한 사용자의 회고다. 빈도·다운타임·비용·원인별 통계는 아직 수집하지 않았다.

| 경험 | 현재 이해한 문제 | 아직 확인하지 않은 것 |
|---|---|---|
| 탈거 후 시험 장비가 금방 고장나 곤란했던 경험 | 필요한 시점에 ATE를 사용할 수 없는 상황 | 고장 난 구성품, 전조, 실제 발생 빈도 |
| 대상 장비 정비 주기와 ATE 정비·점검 주기가 맞지 않았음 | 시험 수요와 시험 장비 사용 불가 기간의 충돌 | 사전 통지·계획 방법과 실제 지연 규모 |
| ATE 전체 대신 오실로스코프 등 모듈을 따로 떼어 정기 정비에 보냄 | 모듈 단위의 반출·복귀·일정 관리 | 실제 교정 대상·반환 확인 항목·기존 관리 도구 |
| 외주 서류 처리가 힘들었음 | 정비 의뢰·결과 인수 과정의 문서 부담 | 반복 기입·보완 요청 등 어느 단계가 가장 힘들었는지 |
| ATE 보드 문제로 보드를 떼어 납땜하거나 멀티미터로 측정함 | 보드 단위의 고장 확인·수리 작업 | 고장 종류, 측정·수리 기록 방식, 재발 여부 |
| 케이블·어댑터도 고장이 있었던 것 같다고 회고함 | 연결 부품의 이상 가능성 | 단선·접촉 불량 등 구체 유형과 재현 조건 |

ATE는 자동시험장비(Automatic Test Equipment)를 뜻한다. 이번 설명에서 관리 대상은 ATE 전체뿐 아니라 구성 계측기·모듈·보드·케이블·어댑터다. 모듈을 따로 보내는 흐름을 ATE 전체를 통째로 외주 정비에 보내는 방식으로 바꾸어 기록하지 않는다.

일정 충돌, 교정 상태, 실제 고장은 서로 다른 문제다. 정비 주기를 무조건 같게 만드는 것보다 필요한 시험 시점의 가용성을 확인하는 접근을 논의했다. 외부 온도·전력 센서가 정상이라고 ATE의 측정 정확도나 교정 유효성이 확인되는 것은 아니다.

## 4. 추천과 논의가 바뀐 과정

1. **초기 트랙 비교:** T2-1은 하드웨어 준비가 불확실할 때 공개 자료로 근거 있는 소프트웨어 시연을 만들 대안이었다. T4-6은 정비 경험과 연결되지만 RUL 데이터가 부담이었다. T4-7은 장비 교육, T4-8은 실제 IMU 입력과 시뮬레이터 비교를 만들 수 있어 검토했다. 이 추천에는 당일 완성·시연 가능성에 무게를 둔 판단이 있었다.
2. **하드웨어 선호 확인:** 사용자는 직접 물건을 만들고 싶다고 밝혔다. T2-1을 자동 우선 선택할 이유가 줄었으며, IMU 조종기도 모터·기구가 움직이는 물건과는 다르다는 점을 구분했다.
3. **정비 경험으로 구체화:** 초기에는 냉각·열 감시, 간헐 이상 기록, 보관·취급 이력 태그, 시험대 자체 상태 확인 등을 넓게 검토했다. 이후 사용자가 ATE 고장·모듈 점검·외주 서류·보드 수리·연결 부품 문제를 설명하면서 논의를 좁혔다.
4. **실물 경쟁력 검토:** 단순 검사기나 관리 화면만으로 기존 제품 대비 차별화를 주장하기 어렵다고 판단했다. 실제 입력, 문제 재현, 판단 근거와 비교 결과를 보여주는 시연을 제안했다. 수상 가능성이나 다른 팀 대비 우위를 검증한 것은 아니다.
5. **T4-7 실물 훈련 키트 제안:** 범용 저전압 교육 회로 한 종류와 두 고장 상황, 실제 계측, 적응형 힌트, 새로운 문제의 수행 비교를 제안했다. 구현하거나 채택하지 않았다.
6. **최신 결정:** 사용자가 T4-6으로 고정했다. T4-7 제안은 미채택 검토 이력으로만 남기고, 앞으로는 T4-6의 필수 요구를 만족하는 구체 문제를 선정한다.

현재 선택할 특정 고장·부품은 확정되지 않았다. 실제 장비 고장 빈도나 시장 공백을 입증한 상태도 아니다. 이 중 어느 후보도 현재 T4-6 전체 요구를 충족했다고 보고할 근거는 없다.

NASA 일부 데이터의 직접 다운로드 제한도 확인했으므로 링크 존재를 즉시 사용 가능한 데이터 확보로 바꾸지 않는다. 다른 장비의 공개 RUL 실험과 우리 실물의 이상 감지 시연은 각각의 개념검증이며, 합쳐서 우리 장치의 수명 예측 정확도라고 말할 수 없다.

## 7. T4-6에서 현직자 검토를 견디기 위한 선정 기준

**공식 요구:** 기존 장비에 부착하는 저가 무선 센서 → 엣지 이상 감지·잔여수명(RUL) 추정 → 정비 우선순위. [T4-6 요구와 근거](T4.md)

아래는 사용자가 강조한 엄격한 검토 환경에 대응하기 위한 내부 기준이다. 현재 이를 통과한 최종 아이디어는 없다.

| 확인할 질문 | 선택 전에 필요한 근거 | 현재 상태 |
|---|---|---|
| 정확히 어떤 부품의 어떤 고장·열화를 다루는가? | 유지보수 가능한 대상 하나, 고장 종료 조건, 해당 경험 | ATE 관련 불편만 확인. 대상 미정 |
| 고장이 나기 전에 무엇이 변하는가? | 측정 가능한 신호와 열화의 연결 근거 | 신호·센서 미정 |
| 기존 점검·자체시험·교정·검사기로 왜 충분하지 않은가? | 현직자의 실제 작업 비교, 누락·대기·접근성 등 구체 차이 | 기존 제품 기능 조사만 완료 |
| 부착 장치가 원래 시험을 방해하지 않는가? | 부착 위치·측정 방식·전원·통신 조건과 검증 방법 | 설계·현물 시험 전 |
| RUL 숫자는 어디서 나오는가? | 고장까지의 데이터 또는 명시적 합성 가정, 향후 사용 조건, 평가 오차·불확실성 | 데이터 선정·평가 전 |
| 예측을 보고 어떤 정비 결정을 바꾸는가? | 점검·교체·대체 장비 준비 등 실제 조치와 우선순위 근거 | 사용자·정비 흐름 확인 전 |
| 실제로 검증할 수 있는가? | 정상·열화·고장 구분, 기존 방법과 비교, 오경보·누락·시간 기록 | 실험 전 |
| 오늘 자원으로 어디까지 가능한가? | 부품 목록, 실제 계측 한 경로, 구현 범위와 담당 | 현장 장비 확보만 확인 |

현직자에게 확인할 핵심은 일반적인 호응보다 **반복되는 구체 고장, 사전 징후의 유무, 현재 점검 방법의 한계, 예측이 바꿀 조치**다. 일반 공개 가능한 경험으로 확인하며 특정 기종의 비공개 정비 문서가 있어야만 성립하는 아이디어를 기본 전제로 삼지 않는다. 아직 현직자 인터뷰나 승인 결과를 수집하지 않았다.

## 8. 경쟁력과 시연에 대해 합의되지 않은 제안

- 사용자 목표는 다른 팀과 경쟁할 만한 결과물이다. 현재 아이디어의 수상 가능성이나 우위는 확인하지 않았다.
- 오늘 오전 확인한 1차 배점은 문제 적합성 25%, 군 적용 가능성 30%, 기술 구현 25%, 창의성 20%다. 하드웨어 규모만으로 평가를 예측하지 않는다. [공식 확인 기록](2026-10-10-day-of-check.md)
- AI가 제안한 시연 기준은 실제 물리 입력, 재현 가능한 변화, 판단 근거, 정비 행동과 연결되는 결과다. 외형·영상·대시보드만으로 실제 센싱이나 예측을 대신하지 않는다.
- 범용 저전압 모사체에 숨긴 이상을 넣고 수동 확인과 검출 시간·누락·오경보를 비교하는 방식도 논의했다. 이는 진단 검증 제안이며 RUL 검증을 대체하지 않는다. 아직 실행하지 않았다.
- A1 mini의 패널·받침·지그는 결선·측정 반복성을 돕는 후보 용도다. 치수·출력 시간·강도와 동작을 확인한 설계는 없다.

## 9. 이전에 제안한 선택 절차

현재는 사용자 요청에 따라 발산을 계속한다. 아래 절차는 이후 선택 단계로 전환할 때 참고할 이전 제안이다.

1. 선택 단계에서는 T4-6 안에서 반복되는 고장·열화 대상 하나와 그 근거를 비교한다.
2. 해당 현상의 전조·측정·RUL 자료·정비 조치를 연결한다. 연결 근거가 없으면 현재 고장 탐지나 자산 관리와 구분한다.
3. NUCODE 모델, 센서·부품 종류, 실제 계측 경로를 확인한다. 보유 장비만으로 기능과 호환성을 단정하지 않는다.
4. 축소한 범위·공개/합성 자료의 인정 여부를 운영진에게 확인한다. 답을 받기 전 승인된 것으로 기록하지 않는다.
5. 선택 후에만 구현 범위·역할·SC·비교 방법을 확정하고 [CONTEXT.md](../CONTEXT.md)에 반영한다.

**현재 결정의 끝:** T4-6 고정과 현장 장비 확보는 사용자 확인 사항이다. 특정 제품 선정, 구현 완료, 현장 효과·수명 예측 검증은 아직 없다.
