# GenGuard 가동 회차 중심 화면 정리 · 2026-10-11

현재 사이트: http://127.0.0.1:9883/

## 사용 흐름

**운전 기록 → 사람이 정상·비정상 검토 → ML 학습·검증 → 다음 운전에 적용 → 운전별 보고서 누적**

1. **운전 현황**: 현재 상태, 실측 진동, 모의 발전기 계측, 선택한 그래프, 점검 권고를 한 화면에서 확인합니다. `운전 기록 시작`을 누르면 기록 이름을 입력하는 연결 화면으로 이동합니다. 실측 기록 중에는 종료·검토로 이어집니다.
2. **기록 · 정상 검토**: 끝난 운전 전체 또는 구간에 정상·비정상·판단 보류·측정 오류를 지정합니다. 검토자와 근거, 학습/보정/검증 역할을 저장합니다. 자동으로 정상 승인하지 않습니다.
3. **학습 센터**: 검토한 기록을 골라 정상 기준 또는 정상·비정상 분류기를 실제 학습합니다. 후보마다 학습에 쓴 운전 수, 학습 시간, 별도 검증 결과를 확인하고 다음 운전 적용을 선택합니다.
4. **분석 보고서**: 운전 시작·종료 시각, 분석 창 수, 당시 적용 모델과 판단, 사람의 검토, 점검 조치를 회차별로 남깁니다. 새 모델을 적용해도 지난 보고서의 판단은 바뀌지 않습니다.
5. **센서 · 입력 연결**: IMU 연결·정상 기준과 기록 시작 설정을 다룹니다.

현재는 담당자가 기록 시작/종료를 선택합니다. 자동 시동 감지로 운전 기록을 자동 생성·종료하는 기능을 구현했다고 주장하지 않습니다. 기존 진동에 연동한 모의 시동·정지는 계속 동작합니다.

## 이번 화면 변경

- 운전 현황의 큰 질문형 제목, 설명 문단, 반복 안내와 세부 학습 설정을 줄였습니다.
- 기존 다섯 개 메뉴를 유지하고 대시보드에는 누적 기록 수·검토 대기·현재 학습 기준만 간단히 표시합니다.
- 현재 창과 1280×800, 1440×900에서 운전 현황 전체가 세로·가로 넘침 없이 표시되는지 확인했습니다. 작은 모바일 화면은 읽을 수 있도록 스크롤을 허용합니다.
- 실측 IMU와 진동 연동 모의 계측의 출처를 카드 묶음과 상단에 유지했습니다. 세부 계측 설명은 다른 화면과 툴팁에서 확인할 수 있습니다.

## 기존 학습과 새로운 학습 구분

- 기존 진동 정상 기준 `imu-a9bad4ae32431366e759`는 그대로 적용합니다. 이번 화면 정리 때문에 재학습하거나 수치를 바꾸지 않았습니다.
- 기존 발전기 모델 `gg-61d42414c27fc19fa7a5`와 원래 진동 기록을 유지합니다.
- 검토 기록으로 만드는 새 모델은 별도입니다. 현재 실측 기록 3회는 미검토이며, 새 정상·비정상 분류기를 이미 학습했다고 표시하지 않습니다.
- 정상·비정상 ML 학습 자체는 앞서 UNO Q의 격리된 합성 기록으로 실행·검증했습니다. 실제 발전기 고장 성능을 검증한 결과는 아닙니다.
- 학습할 최소 독립 운전 수와 검토 방법은 [통합 사용 안내](REVIEW_LEARNING_HANDOFF.md)를 따릅니다.
