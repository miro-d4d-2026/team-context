# GenGuard 현재 상태 · 실측 ML 적용 · 2026-10-11

**정상·비정상으로 검토한 실측 진동 기록으로 UNO Q에서 두 모델을 학습·평가·적용했고, 새 운전에서 판단 전환을 확인했습니다.** 자세한 집계는 [실측 학습 결과](LIVE_LEARNING_RESULT.md), 사용 순서는 [자동 학습 안내](AUTO_LEARNING_GUIDE.md)를 따릅니다.

## 현재 사용할 수 있는 흐름

- 상단은 `모의 운전 / 실측 운전` 두 가지입니다. 과거 아이폰 실험 재생은 `분석 보고서 → 과거 진동 재생`에 있습니다.
- 운전 현황에서 실측 IMU 수신·기존 진동 기준과 진동 연동 모의 계측을 확인합니다.
- 기록에서 정상·비정상·판단 보류·측정 오류를 검토합니다. 사용자가 학습·보정·검증 역할을 지정하는 기능은 없습니다.
- 같은 장비·설치·출처의 승인 기록으로 `AI 학습`을 실행하면 시스템이 운전 회차별로 자료를 나누어 학습·평가합니다.
- 정상만 충분하면 정상 기준 모델을 만들고, 정상·비정상 사례가 충분하면 분류기도 학습합니다. 평가 분모와 자료 부족을 표시합니다.
- 성능 확인 후 `새 모델 적용`을 실행하면 다음 운전부터 사용합니다. 새 기록은 검토 후 누적하고, 필요할 때 같은 기능으로 재학습합니다. 기존 보고서는 보존합니다.
- 현재 새 검토학습 모델의 실측 추론은 `운전 기록 시작` 중에 수행합니다. 기록하지 않을 때는 기존 부착 기준으로 진동을 감시합니다. 웹 서버·학습·추론·저장은 UNO Q, Mac은 브라우저·USB 연결 담당입니다. 전원 재부팅 후 자동 시작은 아직 없습니다.

## 코드 검증 이력

- 후속 모드 명칭 정리: 상단 실측 운전과 과거 재생 분리, JavaScript **161개 통과**. UNO Q 적용 후 과거 재생 진입·구간 이동·실측 복귀 확인. 기존 학습 모델 2개·운전 기록 8개 보존 및 센서 수신 복구 확인.
- 이번 정리: 사용되지 않는 화면 코드 정리, 로컬 코드 커밋 `45a6383`. 관련 JavaScript **160개 통과**.
- 백엔드는 이번 정리에서 변경하지 않았습니다. 앞선 자동 학습 기능의 전체 Python **270개 통과** 결과를 유지하며, 이를 이번에 재실행한 결과로 표기하지 않습니다.
- 앞선 화면의 JavaScript **164개 통과**는 정리 전 이력입니다. 현재 화면 검증은 위 160개 결과를 따릅니다.
- 앞선 격리된 합성 데이터 시험에서는 초기 학습·누적 재학습·명시적 적용·새 운전·재시작 후 보고서 보존을 Mac과 UNO Q에서 확인했습니다. 이번 실측 확인과 합성 검증을 구분합니다.
- 이번 실측 확인은 실제 UNO Q에서 수행한 학습·평가·모델 적용과 새 운전 판단입니다. 이전의 실측 3회 미검토 상태는 위 검토·추가 수집으로 갱신되었습니다.

## 실행과 게시 범위

개발 실행은 [README](README.md), 기존 UNO Q 배치 재시작은 [보드 안내](deployment/UNO_Q_RUNBOOK.md)를 따릅니다. 이 기능은 생성형 AI·고장 확률·고장 부위 확정·RUL 모델이 아닙니다. 실제 발전기와 추가 온도·압력 센서의 현장 검증은 수행하지 않았습니다.

GitHub 게시본은 공개 가능한 코드와 집계 결과만 포함합니다. 실제 운영 DB, 개인 모델 계수·부착 기준, 원시 센서 캡처와 기기별 설정은 제외합니다. 로컬 검증 원본도 이 게시본에 포함되지 않을 수 있습니다. 런타임 필수 합성 seed DB인 `model_bundle/baseline.sqlite`만 예외로 포함하며, 여기에는 실제 운전 데이터가 없습니다. 공개 코드만 실행하면 개인 실측 모델과 운영 기록은 자동 복원되지 않습니다.

[이전 검증 이력](docs/PRE_AUTO_CURRENT_STATUS.md)은 당시 상태이며 현재 UI·모델 적용 상태와 구분합니다.
