# 추세 실험 결과를 읽는 방법

- `model.json`: 합성 운전 320회를 이용해 Ridge 미래 변화량 모델을 학습했다. 별도 보정 운전 96회에서 Ridge·직선 추세·현재값 유지 방법을 비교했다. 최종 선택은 **두 항목 모두 직선 추세**다. Ridge 가중치는 포함하지만 운영 예측에 선택하지 않았다.
- `evaluation.json`: 선택 과정에서 사용하지 않은 **4000–4019 시드 × 8개 시나리오 = 160회** 결과다. 정상 기준은 기존 v1 합성 데이터의 조건별 정상식에 맞췄다. 실제 발전기 자료가 아니다.
- `training-summary.json`: 위 최종 평가의 핵심 숫자다.
- `exploratory-strict-band-evaluation.json`: 초기 탐색 기록이다. 이전 정상 배경식과 3000–3019 시드를 사용했고, 오차 범위 전체가 경계 밖이어야 경고하는 정책이었다. **최종 모델의 평가가 아니며 최종 결과와 같은 조건의 정책 비교로 사용하면 안 된다.** 탐색 뒤 별도 보정 데이터로 정책을 정하고, 정상 배경식을 기존 시스템과 맞춘 뒤 새로운 4000번대 시드로 최종 평가했다.

## 이번 결과

| 2분 후 예측 MAE | Ridge | 직선 추세 | 현재값 유지 |
| --- | ---: | ---: | ---: |
| 수온 °C | 1.1958 | 1.1712 | 1.3550 |
| 유압 kgf/cm² | 0.11013 | 0.10964 | 0.13377 |

학습 모델이 간단한 직선 추세보다 낫다는 근거를 얻지 못했다. 이 결과를 보고 모델·정책을 다시 조정하지 않았다.

- 수온 상승·유압 하락·동시 악화 60회에서는 해당 채널의 시연 경계 전에 알림을 냈다. 같은 채널 기준 중앙 선행 시간은 각각 90초·100초·90초였다.
- **일시 변화 후 복귀 시나리오에서는 20회 중 14회에 불필요한 알림을 냈다.** 과거 상승 흐름만으로 앞으로의 회복을 알 수 없다는 한계가 드러났다.
- 정상 유지·부하 변경·갑작스런 계측 변경·별도 완만한 회복 시나리오는 각각 20회 중 사전 알림이 0회였다. 위 일시 변화 시나리오의 실패를 상쇄하는 의미가 아니다.
- 경계는 수온 92°C 이상, 유압 2.0 kgf/cm² 미만의 **시연 가정**이다. 발전기 제조사 보호 기준이나 고장 시점이 아니다.
- 오차 범위는 합성 보정 자료의 절대오차 90백분위다. 실제 발전기의 신뢰구간이나 고장 확률이 아니다.

현재 이상 탐지보다 먼저 유용한 조치를 가능하게 하는지는 별도로 비교해야 한다. 이 모듈의 역할은 개선이 확인된 제품 기능을 주장하는 것이 아니라, 추세 예측의 추가 가치와 오경보를 실제 코드로 검토하는 실험이다.
