# GenGuard 실측 검토·학습·모델 적용 결과

2026-10-11 · Arduino UNO Q · 같은 아이폰과 IMU 부착 환경

**실제로 측정한 진동 기록을 검토하고, UNO Q에서 정상 기준 모델과 정상·비정상 분류기를 학습·평가한 뒤 적용했습니다. 모델 적용 후 새 운전에서도 기준·강함·간헐 진동에 따른 판단 전환을 확인했습니다.**

## 무엇을 학습했나

입력은 실측 가속도로 계산한 진동 RMS와 진동 세기의 시간 변동성입니다. 아이폰의 기준 진동을 정상, 강한 진동과 간헐 진동을 비정상 **시연 자극**으로 검토했습니다. 이 라벨은 실제 발전기의 정상·결함 판정이 아닙니다. 아이폰 버튼 이름이나 재생 순서는 모델 입력에 넣지 않았습니다.

사용자가 자극 실행을 확인한 기록에 따라 구간을 검토했습니다. 시작·전환 직후의 여유 구간은 제외하고, 검토한 구간 안에 완전히 포함되는 2초 분석 창만 사용했습니다. 수집을 각각 시작하고 종료한 4회 기록을 유지했으며, 한 녹화를 잘라 독립 회차 수를 늘리지 않았습니다.

| 기록 | 정상 창 | 강한 진동 창 | 간헐 진동 창 | 시스템이 정한 용도 |
|---|---:|---:|---:|---|
| 실측 1회 | 33 | 17 | 17 | 학습 |
| 실측 2회 | 33 | 17 | 17 | 학습 |
| 실측 3회 | 33 | 17 | 17 | 판단 경계 보정 |
| 실측 4회 | 33 | 17 | 17 | 후보 평가 |
| 합계 | **132** | **68** | **68** | **유효 창 268개** |

정비사는 구간의 상태를 검토하고 `AI 학습`을 실행합니다. 학습·보정·평가의 역할 분리는 시스템이 처리했습니다. 정상 기준 모델은 위 기록의 정상 132창만 사용하고, 분류기는 정상 132창과 비정상 136창을 사용했습니다.

## UNO Q에서 실제로 학습한 모델

| 모델 | 학습하는 내용 | 후보 평가 결과 | 학습 시간 | 적용 상태 |
|---|---|---|---:|---|
| 정상 기준 `review-4f2f18fe0b80` | 정상 특징의 기준과 잔차 공분산 | 별도 1회 정상 33창 중 범위 이탈 **1/33 (3.03%)**, 유효 분석 **33/33** | 약 0.159초 | 적용됨 |
| 정상·비정상 분류 `fb-85695ee21e12` | 검토 라벨에 맞춰 표준화 값과 이차 로지스틱 분류 계수 학습 | 별도 1회 정상 오분류 **0/33**, 비정상 검출 **34/34**, 미검출 **0/34** | 약 0.142초 | 적용됨 |

정상 기준 모델은 `context-ridge-residual-covariance/1` 계산 코어를 사용합니다. 이번 진동 전용 프로필에는 부하 같은 조건 입력이 없으므로 진동의 정상 분포를 학습했습니다. 분류 모델은 `genguard-reviewed-quadratic-logistic/1`입니다. 결과는 저장된 과거 사례 검색이나 정해진 화면 문구의 재생이 아니라, 학습한 모델에 새 측정 특징을 입력해 계산합니다.

두 후보 모두 설정된 평가 조건을 통과한 뒤 명시적으로 적용했습니다. 정상 모델의 범위 이탈 비율은 분석 창 단위 지표이며, 지속 조건을 거치는 화면 경보의 발생 횟수와 같지는 않습니다. 정상 모델의 이번 후보 평가에는 비정상 창을 넣지 않았으므로 이 표에서 해당 모델의 비정상 검출률을 주장하지 않습니다.

## 모델 적용 후 새 운전

5번째 기록 `run-ffdfaed6210b`는 위 두 모델의 학습·보정·후보 평가에 사용하지 않은 새 수집입니다. 다음 운전이 두 모델 ID를 사용한 상태에서 각 자극의 안정 구간을 확인했습니다.

| 새 운전 자극 | 확인한 창 | 정상 기준 모델 | 라벨 분류 모델 |
|---|---:|---|---|
| 기준 진동 | 6 | 기준 범위 `reference` **6/6** | 정상 유사 `normal_like` **6/6** |
| 강한 진동 | 6 | 점검 권고 `attention` **6/6** | 비정상 유사 `abnormal_like` **6/6** |

새 운전에는 총 59창이 기록됐지만, 위 결과는 시작·전환·대기를 제외하고 검토한 **18창**에 대한 확인입니다. 나머지 창까지 모두 정답 판정을 했다는 뜻은 아닙니다. 이 5번째 기록도 구간 라벨과 보고서를 저장했으며, 적용 중인 모델을 만들 때에는 사용하지 않았습니다.

## 기존 기록과 기준 보존

- 기존 반복·랜덤 녹화 2회도 25개 구간으로 검토했습니다. 총 96창 중 정상 24창, 비정상 46창, 판단 보류 26창입니다. 정지 자극과 원인 미상 충격을 보류에 포함했습니다.
- 이 두 기록은 라벨별 길이가 부족하고 현재 실측과 설치·설정 조건이 달라 이번 모델 학습에 합치지 않았습니다. 각 원녹화는 그대로 하나의 독립 기록입니다.
- 별도의 짧은 수신 확인 기록 4창은 판단 보류로 남겼습니다.
- 기존 실시간 진동 기준과 고정 모델 파일의 해시는 변경 전과 같습니다. 실제 운영 DB와 원시 기록은 보드에 백업했습니다.

## 결과를 설명하는 범위

이번 결과는 **같은 아이폰·센서 부착 환경 한 곳에서 측정한 반복 실험**입니다. 후보 분류기의 정상 오분류 0/33·비정상 검출 34/34는 별도 회차 하나의 67창 결과이며, 67개의 독립 실험이나 일반 정확도 100%를 의미하지 않습니다. 추가 새 운전 확인도 같은 환경의 짧은 18창입니다.

실제 발전기 고장 부위, 수명, 다른 부착 환경에서의 정확도는 검증하지 않았습니다. 이번 실측 학습에는 모의 수온·유압·전압을 섞지 않았습니다. 따라서 설명 가능한 성과는 **실측 기록의 검토 → UNO Q ML 학습 → 회차를 분리한 평가 → 모델 적용 → 새 실측 판단**의 연결입니다.

이 문서는 공개 가능한 집계 결과입니다. 검증 원본에는 개인 부착 조건·모델 계수·상세 센서값이 포함되어 별도로 보관하며 GitHub 게시본에 넣지 않습니다. 운영 데이터 없이 공개 코드만 실행하면 여기의 개인 모델이 자동 복원되는 것은 아닙니다.
