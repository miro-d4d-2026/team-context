# 참고 디자인 적용 · 2026-10-11

원본 `user-provided-local-reference`는 변경하지 않았습니다. 네이비 사이드바/청록 강조/흰 카드와 다섯 메뉴를 기존 UNO Q 웹에 적용했습니다.

| 메뉴 | 연결한 기존 기능 |
|---|---|
| 운전 현황 | 실측 진동, 정상 기준 RMS, 시간 변동성, 모의 발전기 계측, 현재 점검 권고 |
| 기록 · 정상 검토 | 저장된 점검 조회, 모의 현재 점검 저장, 저장 시 정상 확인 |
| 학습 센터 | 실제 진동 기준 ID·수집 구간, 모의 과거 운전 기록 기반 재학습 |
| 분석 보고서 | 이전 점검과 같은 구간의 변화량·모델 기대 변화율·점검 근거 |
| 센서 · 입력 연결 | IMU 수신/품질/설정, 정상 기준 등록, 34개 계측·수기점검 목록 |

## 보존한 것

기존 데이터·기준·규칙·모델·API를 유지했습니다. 참고본의 별도 구간 라벨/비정상 분류기/후보 활성화 엔진은 이번 디자인 변경에 추가하지 않았습니다. 학습센터 버튼은 기존 API의 실제 정상 기록 학습에 연결됩니다. 혼합 실측+모의 데이터를 하나의 발전기 학습 이력으로 저장/학습하지 않는 제한도 유지합니다.

진동 Peak는 현재 계약에 없으므로 계산해서 만들어 넣지 않았습니다. 대신 정상 기준 RMS와 시간 변동성을 표시합니다. 원래 단위 kgf/cm²도 유지했습니다.
