# 예측을 추가할 가치가 있는가? — GenGuard v3 실험 결과

**결정: 현재 정상 패턴 대비 이상 탐지를 주 기능으로 유지하고, 추세는 별도 실험 보조 기능으로 둡니다.**

이 실험은 현재값 분석만으로 충분한지 판단하기 위해 만든 것입니다. 새로운 모델의 우월성을 전제로 하지 않았습니다. 아래 숫자는 합성 운전의 비교 결과이며, 실제 발전기 성능이나 정비 비용 절감을 검증한 수치가 아닙니다.

## 새로 구현한 기능

- 최근 120초의 수온·유압·부하·외기온·RPM 이력으로 120초 뒤 수온·유압을 추정합니다.
- 지속 악화와 경계 접근 예상이 3회 이어지면 실험용 점검 권고를 표시합니다.
- 미래 회귀 모델(Ridge)을 학습하고, 현재값 유지·단순 직선 추세와 비교합니다.
- 동일 운전 조건 확인, 수집 간격/품질/급변/회복 확인을 통과한 경우만 추정합니다.
- 실제 IMU 이상 탐지는 유지하며, 이 미래 예측과 혼합 학습하지 않습니다.

## 정직한 비교 결과

| 항목 | 학습한 Ridge | 직선 추세 | 현재값 유지 |
|---|---:|---:|---:|
| 수온 MAE (°C) | 1.1958 | 1.1712 | 1.3550 |
| 유압 MAE (kgf/cm²) | 0.1101 | 0.1096 | 0.1338 |

두 항목 모두 독립 보정 운전에서 **직선 추세가 선택**됐고, 마지막 평가에서도 Ridge보다 오차가 조금 작았습니다. 회귀 모델은 실제로 학습했지만, 학습한 모델이 항상 더 나은 것은 아니므로 채택하지 않았습니다. 화면의 새 예상선은 현재 직선 추세입니다. 기존 정상 패턴 모델은 계속 머신러닝을 사용합니다.

| 시나리오 | 평가 운전 | 현재 이상 알림 | 추세 권고 | 고정 경보 | 기존 감지보다 추세가 먼저인 운전 |
|---|---:|---:|---:|---:|---:|
| 정상 유지 | 20 | 0 | 0 | 0 | 0 |
| 수온 점진 상승 | 20 | 20 | 20 | 20 | 0 |
| 유압 점진 하락 | 20 | 20 | 20 | 20 | 0 |
| 수온·유압 동시 악화 | 20 | 20 | 20 | 20 | 0 |
| 일시 변화 후 복귀 | 20 | 20 | 14 | 0 | 0 |
| 부하 변경 | 20 | 14 | 0 | 0 | 0 |
| 계측값 갑작스런 변경 | 20 | 20 | 0 | 0 | 0 |
| 악화 후 회복 | 20 | 20 | 0 | 0 | 0 |

**지속 악화 60회 모두 기존 현재 이상 탐지가 추세 권고보다 먼저 발생했습니다.** 추세는 고정 경보보다 중앙값 약100~110초 먼저 알렸지만, 기존 이상 탐지보다 중앙값 약305~365초 늦었습니다. 따라서 ‘더 일찍 발견하는 기능’의 추가 이득은 이 모의 실험에서 확인되지 않았습니다.

**일시 변화 후 복귀 20회 중14회에서 추세 권고가 예상한 경계 도달이 발생하지 않았습니다.** 이 실패를 숨기지 않고 화면과 보고서에 남겼습니다. 반면 일시 변화 때의 기존 이상 탐지는 현재 실제로 달라진 값을 발견한 것이므로, 미래 경계를 틀린 추세 오경보와 같은 의미로 세면 안 됩니다. 부하 변화14회에서도 기존 모델의 현재 편차 알림이 발생해, 현재 모델 역시 전환 구간 처리와 현장 보정이 필요합니다.

## 검증 경계

- 합성 운전320회 학습,96회 보정,160회 최종 평가. 운전의 시간창을 무작위로 섞지 않았습니다.
- 학습 입력은 현재까지의 이력이고 정답은120초 뒤의 실제 합성 관측입니다. 시나리오 이름·미래 전환 시각을 모델 입력에 넣지 않습니다.
- 모델과 경고 정책은 보정 단계에서 선택했습니다. 개발 중 보았던3000번대 운전은 최종 평가에서 제외했고,4000번대160회 결과 이후 성능을 맞추기 위한 재조정은 하지 않았습니다.
- 정상 배경식은 기존 고정 데이터의 정상식과 맞췄습니다. 여전히 같은 합성 생성 계열을 평가한 것이며 현실로의 일반화 검증이 아닙니다.
- 모든 경고 비교는10초 공통 표본입니다. 실제2초 입력의 기존3창 감지는 이 비교보다 최대16초 빠를 수 있습니다.
- 모델 평가의 경계 도달은 수온92°C·유압2.0kgf/cm² 미만이라는 시연 가정입니다. 고정 경보에는5초 지속 확인을 추가하므로 원시 경계 도달보다10초 늦을 수 있습니다.
- 경고의 정답 여부는 권고한 동일 채널이120초 안에 경계를 넘었는지 확인합니다. 관측 끝 이후의 알 수 없는 미래는 오경보로 단정하지 않습니다.
- 오차 띠는 합성 보정 운전의 절대오차90분위수입니다. 개별 발전기의90% 신뢰구간이나 고장 확률이 아닙니다.
- 정비사의 행동 변화, 실제 점검에 필요한 시간, 고장·비용 감소는 이번 실험으로 확인하지 않았습니다.

## 제품 판단

GenGuard에 예측이 반드시 있어야 하는 것은 아닙니다. “같은 운전 조건에서 이전보다 상태가 달라졌으니 근거를 보고 점검한다”는 현재 기능이 목적에 맞습니다. 이번2분 추세는 진행 방향을 설명하는 데 쓸 수 있지만 주 경보에 합칠 근거는 부족합니다. 그래서 v3는 기존status/alerts를 바꾸지 않고 별도 실험 카드와trend_notification_events에만 표시합니다.

주1회 또는2주1회 시험 운전을 하는 장비라면 후속 우선순위는 **여러 시험의 동일 단계·부하·외기 조건을 맞춘 변화 비교**입니다. 예를 들어 안정화 시간, 안정운전 수온·유압, 진동 특징의 점검 회차별 변화가 중요합니다. 이 장기 비교 기능은 이번에 구현한2분 추세와 다른 기능이며 아직 추가하지 않았습니다.

발표 표현: “장비별 정상 패턴을 학습해 상태 변화를 찾습니다. 악화 추세 예측도 실험했으며, 현재 단계에서는 기존 이상 탐지를 중심으로 하고 추세는 보조 정보로 제공합니다.”

재현: `python train_trend.py` → `python evaluate_value.py`. 그래프와 비교는 웹의 악화 추세 실험에서 확인합니다.
