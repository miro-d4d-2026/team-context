# 팀 저장소 게시 범위

기존 팀 앱을 덮어쓰지 않는 독립 추가 폴더입니다. UNO Q에서 실행한 통합 앱 소스·모델·합성 참고 자료와 이번 자동 학습 검사 결과를 포함합니다.

실제 운영 DB, 개인 부착 정상 기준, 원시 IMU CSV/ZIP, 디바이스별 runtime/config, 이전 화면 캡처·전체 검증 폴더는 게시하지 않았습니다. 일부 과거 문서의 로컬 검증 링크는 원본 작업 폴더에 보존되어 있습니다. 최신 사용·검증은 README.md와 CURRENT_STATUS.md를 기준으로 합니다.

baseline.sqlite는 합성 seed DB이므로 예외로 포함합니다. 진동 실험의 frozen-original.json은 기존 모델·검사가 원문 해시로 고정한 출처 기록이라 경로 문자열까지 원문 그대로 보존합니다. 해당 경로의 원시 파일은 게시하지 않습니다. 문서의 개인별 실행 경로는 일반화했습니다. 나머지 모델·분석 코드는 작업 폴더와 같습니다. SHA256SUMS.txt는 이 게시본 파일 기준입니다.

사용자 제공 GenGuard_Label_Learning_v2 화면·흐름을 참고하고 기존 팀 조건부 회귀 코어를 연결했습니다. 팀 공유 목적의 통합이며 원본에 없는 새 라이선스를 임의로 부여하지 않습니다.
