# 항목별 표시·학습·판단 범위

이전 v4·v5 비교 화면은 **수온·유압·진동 3개를 우선 구현한 시연**이었다. v1 README에서 고정한 계측 항목 자체가 3개로 줄어든 것은 아니다. v6는 기존 `display-fields.json`의 **표시 항목 25개와 수기 점검 9개를 모두 보존**한다. 미수집 값은 미연결로 표시하며, 모두 학습했다는 의미가 아니다.

## 같은 방식으로 비교하지 않는다

| 항목 | 화면 값의 출처 | 판단 방법 | 이번 학습 범위 |
|---|---|---|---|
| 냉각수 온도 | 모의 운전 기록 | 같은 부하·외기온·RPM, 같은 운전 시간 구간의 상승량·상승 속도 비교. 고온 보호 참고값은 별도로 확인 | 승인된 정상 모의 운전 곡선 |
| 윤활유 압력 | 모의 운전 기록 | 시동·안정화에 따른 정상 압력 곡선과 추가 하락 비교. 저유압 보호 참고값은 별도로 확인 | 승인된 정상 모의 운전 곡선. **유온 미수집** |
| 진동 RMS | 모의 값 / 실측 IMU / 실측 기록 재생 | 같은 부착·수집 조건에서 세기 변화 비교. 모의 발전기와 아이폰 실측 기준 분리 | 모의 곡선 모델 또는 기존 실측 진동 모델 |
| 진동 간헐성 CV | 모의 표시 또는 재생 실측 특징값 | 반복 진동·간헐 진동의 시간 패턴 구분 | 아이폰 기록 분류기의 입력. 모의 발전기 곡선 모델에는 넣지 않음 |
| RPM | 모의 입력 | 운전 조건 및 고정 참고 범위 | 정상 곡선의 조건. 별도 RPM 이상 모델은 아님 |
| 부하율 | 모의 입력 | 운전 조건 및 정격 초과 참고값 | 정상 곡선의 조건. 별도 부하 이상 모델은 아님 |
| 주변 온도 | 모의 입력 | 정상 온도·압력 곡선의 비교 조건 | 조건 입력. 단독 고장 경보 없음 |
| 선간전압 | 모의 입력 | 208 V 기준의 시연 범위 확인 | 학습하지 않는 고정 규칙 |
| 배터리 전압 | 모의 입력 | 12 V 계통을 가정한 시연 범위 확인 | 학습하지 않는 고정 규칙 |
| 연료 잔량 | 모의 입력 | 시연 저잔량 기준 확인 | 학습하지 않는 고정 규칙 |
| 출력 주파수 | RPM÷30 계산 | 직결 4극 가정. RPM과 독립된 정보가 아님 | 중복 학습·독립 주파수 진단 제외 |
| 출력 | 부하율×10 kW÷100 계산 | 선택한 가상 10 kW 정격으로 계산 | 독립 전력계 값이 아님 |
| 상전류 | 출력÷(√3×선간전압×역률) 계산 | 균형 3상 가정. 역률 또는 전압이 0·결측이면 계산 불가 | 독립 전류 진단·상불평형 진단 제외 |
| 역률 | 모의 입력 | 전류 계산 조건 | 학습·단독 경보 제외 |
| 습도 | 모의 표시 | 환경 정보 | 학습·경보 제외 |
| 누적 운전시간 | 모의 표시 | 누적 시간만 표시 | RUL 또는 정비 주기로 해석하지 않음 |
| 전압 측정 위치·전류 측정 상·예열 | 모의 선택·운전 단계 | 측정 위치와 운전 단계를 명시 | 상태 표시만 |
| 상별 전류·충전전류·표면온도·윤활유 온도 | 미연결 | 값을 추정해서 채우지 않음 | 학습·판정 불가 |
| 기존 보호기·차단기 | 미연결 | 앱 알림과 실제 정지/차단 상태 구분 | 앱 알림으로 보호동작 발생을 만들지 않음 |

수온의 `10분 값 − 5분 값`을 기준 기록의 같은 구간과 비교한다. 총 가동 시간이 다르면 단순 현재값·전체 평균으로 비교하지 않는다. 사용자가 제시한 `+10 → +8 → +5 → +5°C`는 **구간별 변화량의 예시**이며, 실제 발전기의 보편적 정상 곡선으로 채택한 값은 아니다.

## 고정 참고값은 별도로 유지한다

시간에 따른 변화가 정상과 비슷하더라도 절대값이 보호 참고값에 도달했다면 무시하지 않는다. 반대로 절대값이 참고 범위 안이어도 운전 구간별 변화가 평소보다 크면 점검 권고가 가능하다.

| 항목 | 시연 점검 참고값 | 긴급 보호 참고값 |
|---|---|---|
| RPM | 1,710 미만 또는 1,890 초과 | 1,980 이상 |
| 냉각수 | 92°C 이상 | 100°C 이상 |
| 윤활유 압력 | 2.0 미만 또는 4.5 초과 kgf/cm² | 0.6 이하 kgf/cm² |
| 부하율 | 100% 초과 | 110% 이상 |
| 선간전압 | 197.6 미만 또는 218.4 초과 V | 별도 미설정 |
| 배터리 | 12.5 미만 또는 15 초과 V | 별도 미설정 |
| 연료 | 20% 미만 | 별도 미설정 |

이 표는 기존 `genguard-alarm-demo-v1/profile.json`을 보존한 것이다. 일반 점검 기준은 **시연 가정**, 긴급 참고값은 **군 구매요구 참고**다. 수온은 문서의 95–100°C 중 100°C를 시연용으로 선택했다. 실제 발전기의 제조사 승인 기준이 아니며 발전기를 제어하지 않는다.

**현재 선택한 표본의 참고값 확인**과 **연속 신호의 경보 유지시간 확인**은 다르다. 5분 간격으로 만든 운전 점들만으로 5초·10초 연속 초과를 확인했다고 표현하지 않는다. 이 카탈로그는 지속시간 미검증을 명시한다.

## 미연결·수기 점검 항목

오일량, 냉각수량, 연료·오일·냉각수 누설, 흡기·공기필터, 연료필터, 라디에이터·통풍, 벨트·호스, 체결·방진마운트, 배선·단자는 모두 **미점검**으로 시작한다. 진동 또는 온도 경고가 나도 이 항목들을 자동으로 고장·정비 완료로 변경하지 않는다.

콘센트 구성, 운전반 종류, 시동 스위치, 상별 계측 구성, 정비 이력, 성능시험 기록은 원래 문서의 장비 메타데이터·기록 범위다. 실시간 센서값이나 학습 입력으로 바꾸지 않는다.

## 코드 연결

- `operation_catalog.catalog()` → 표시 정의 25개 + 수기 점검 9개.
- `operation_catalog.telemetry_for(context, latest, auxiliary, mode, vibration)` → 값·단위·출처·판단 방식이 붙은 행 목록.
- `AUX_FIELDS` → API 숫자 입력 허용 범위. `AUX_DEFAULTS` → 빠진 보조 모의 입력의 시작값.
- 명시적으로 입력한 `null`은 0이나 기본값으로 복구하지 않는다. 미연결 보호기·차단기는 항상 미연결이다.
- 수온·유압·진동의 **학습 결과 상태는 서비스의 실제 모델 응답으로 덮어쓴다**. 이 카탈로그가 모델 예측을 생성하지 않는다.
- 실측 진동 출처는 서비스가 지정한다. 사용자가 모의 수온·유압을 변경해도 실측 발전기 온도·압력으로 바뀌지 않는다.

근거 파일: `../genguard-alarm-demo-v1/README.md`, `display-fields.json`, `profile.json`, `sources-audit.md`. 새 제품 조사나 비용 산정은 이번 변경에 포함하지 않는다.
