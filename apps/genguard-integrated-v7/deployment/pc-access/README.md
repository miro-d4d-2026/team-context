# 다른 PC로 옮겨 쓰는 GenGuard

## 팀원 Mac에서 접속

1. `GenGuard-USB-접속-Mac.zip` 전체를 압축 해제합니다. 실행 파일 하나만 옮기면 안 됩니다.
2. UNO Q를 데이터 통신이 가능한 USB 케이블로 해당 Mac에 연결합니다.
3. `GenGuard-접속.command`를 더블클릭합니다.
4. 전원이 꺼졌다 켜졌으므로 부팅을 기다립니다. 보통 약 1분, 처음엔 더 걸릴 수 있습니다. 이 도구는 준비될 때까지 대기합니다.
5. UNO Q의 분석 서버가 준비되면 브라우저가 자동으로 열립니다. 이 터미널 창을 열어두면 재연결도 자동 복구합니다.

모델·학습 기록·보고서·서버는 UNO Q 안에 있습니다. 새 Mac에 Python·Node·Xcode·모델을 설치하지 않습니다. 접속용 ADB가 포함됩니다. 공식 출처: https://developer.android.com/tools/releases/platform-tools

`127.0.0.1`은 지금 사용하는 PC의 주소입니다. 다른 PC에 URL만 전달하면 접속되지 않습니다. 그 PC에 보드를 연결하고 이 도구를 실행해야 합니다. 동시에 여러 PC에서 접속하는 무선 공유 기능은 아닙니다.

## 전원이 꺼질 때

- 새 PC에 연결하면 UNO Q가 부팅되고 기존 GenGuard 자동 시작 서비스가 실행됩니다. 이 접속 도구는 서버를 중복 실행하거나 DB·모델을 덮어쓰지 않습니다.
- 이미 저장된 모델과 보고서는 유지합니다. 꺼져 있던 동안의 데이터는 만들지 않습니다.
- 보고서 기록 중 전원을 빼면 중단된 운전으로 남을 수 있습니다. 가능하면 `보고서 기록 종료` 후 옮기세요. 새 운전을 보고서로 남길 때만 다시 기록을 시작합니다.
- IMU를 아이폰/장비에서 떼어 부착 위치나 방향이 바뀌면 기존 진동 기준과 비교 조건도 바뀝니다. 전원 이동과 센서 재부착은 구분하세요.
- USB가 유일한 전원이면 케이블을 뽑는 순간 감시도 멈춥니다. 감시를 계속한 채 PC만 바꾸려면 별도 전원과 연결 방식을 설계해야 합니다.

## 안 열릴 때

- 터미널 메시지가 `연결 대기`면 데이터 케이블·USB 포트·보드 연결을 확인합니다.
- `부팅·분석 서버 준비 대기`면 부팅을 기다립니다. 2분 이상 계속되면 보드 서비스 상태를 확인해야 합니다.
- 9883 포트가 다른 앱에서 사용 중이면 도구가 9884~9889 중 빈 포트를 사용하고 그 주소를 엽니다. 표시된 주소를 사용하세요.
- macOS가 실행을 차단하면 시스템이 제공하는 공식 허용 절차를 사용하세요. 보안 기능을 끄거나 권한을 일괄 제거할 필요는 없습니다.
- Windows에서는 이 Mac 실행 파일이 동작하지 않습니다. 공식 Windows Platform Tools의 폴더에서 아래 두 명령을 실행하고 브라우저로 접속합니다. 부팅이 끝나기 전에 열었으면 약 1분 뒤 새로고침합니다.

```text
adb devices
adb -s 233936836 forward --no-rebind tcp:9883 tcp:9883
```

Windows에서도 연결을 뺐다가 다시 꽂으면 두 번째 명령을 다시 실행합니다. 이 Windows 경로는 문서 안내이며 실물 Windows PC에서는 검증하지 않았습니다.
