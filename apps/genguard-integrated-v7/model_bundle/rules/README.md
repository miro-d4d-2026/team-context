# 고정 규칙의 출처

이 폴더의 engine.mjs/profile.json/scenarios.json/sources-audit.md는 기존 `genguard-alarm-demo-v1`에서 변경 없이 복사했다. `sources-audit.md`의 ‘이번 검토’는 2026-10-10 당시의 원문 확인 기록을 의미한다. 이번 모델 재학습에서 군 문서나 웹 원문을 다시 조사한 것은 아니다.

감사 기록에 적힌 `sources/*.pdf`는 원래 연구 폴더에 있는 참조 문서이며 이 전달 ZIP에는 포함하지 않는다. 공개 제조사 원문 URL과 군 문서 관리번호·쪽수·해시는 감사 기록에 남겨 두었다.

점검 임계값은 시연 정책, 일부 긴급 참고값은 군 요구 참고값이다. 학습된 정상 분포와 구분한다. 실제 장비를 정지하거나 제어하는 코드가 아니다.
